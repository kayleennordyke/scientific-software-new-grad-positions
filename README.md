# Scientific Software & Computational Science Jobs

Curated internships and new-grad roles for students in programs like **UC Berkeley MSSE**, computational chemistry, bioinformatics, battery modeling, materials science, and ML for science.

This repo filters the larger [Simplify](https://simplify.jobs/?utm_source=GHList&utm_medium=title) job list to highlight positions where **software intersects with the physical sciences**.

Listings are synced daily from [New-Grad-Positions](https://github.com/SimplifyJobs/New-Grad-Positions) and [Summer2026-Internships](https://github.com/SimplifyJobs/Summer2026-Internships) (via scheduled workflow); only scientific / MSSE-relevant roles are shown here.

🙏 **Contribute by submitting an [issue](https://github.com/SimplifyJobs/New-Grad-Positions/issues/new/choose)!** See [CONTRIBUTING.md](./CONTRIBUTING.md).

---

## Why this is useful for MSSE (and similar programs)

Most people in scientific software / computational science are looking for roles like:

- **Research Software Engineer** · **Computational Scientist** · **Simulation Engineer**
- **ML for Science** · **Bioinformatics Engineer** · **Battery Modeling / Energy Software**
- **Scientific Python developer**

Those roles get buried on generic SWE job boards. This repo is **the MSSE-oriented version of the Simplify list**.
